# VM, Reti e Storage con AWS

Materiali didattici per il corso **"VM, Reti e Storage con AWS"** - ITS ICT Piemonte, System Administrator - AWS Cloud Architect B.F. 2025/2027.

## 📚 About This Repository

Hands-on materials for building a real AWS infrastructure step by step: EC2 instances, VPC networking, EBS/EFS/S3 storage, IAM roles, monitoring, backup and cost optimization. Includes labs, slide decks, and recorded demo scripts, all built for the AWS Academy Learner Lab and its policy limits (regions, instance sizes, LabRole never modified).
