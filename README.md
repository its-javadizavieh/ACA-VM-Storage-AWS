# VM, Reti e Storage con AWS

**VM, Reti e Storage con AWS** - Complete course materials for learning and applying virtual machines, networking, and storage services on Amazon Web Services using EC2, VPC, EBS, EFS, S3, IAM roles, monitoring, backup, and cost optimization.

## 📚 About This Repository

Hands-on labs and solutions for building a real AWS infrastructure step by step: EC2 instances, VPC networking, EBS/EFS/S3 storage, IAM roles, monitoring, backup and cost optimization. All materials are built for the AWS Academy Learner Lab and its policy limits (regions, instance sizes, LabRole never modified).
